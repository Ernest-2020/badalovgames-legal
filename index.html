01Издатель и игра

Политика относится к Android-версии игры «Троецарствие: Путь небес» (com.badalovgames.threekingdoms), обращениям к разработчику и этой странице. Браузерная версия в Яндекс Играх в неё не входит.

Издатель и оператор данных обращений — Эрнест Бадалов, физическое лицо, Россия, бренд badalovgames. Контакт по вопросам игры и персональных данных: badalovgames.help@yandex.ru.

02Сохранения

Прогресс, игровые временные отметки и настройки хранятся на устройстве для продолжения игры и расчёта наград. В Android-версии нет игрового аккаунта и собственного облачного сохранения; издатель не получает сохранения на свой сервер. Android или производитель устройства могут создавать резервные копии и переносить данные в соответствии с настройками ОС.

Игра не запрашивает доступ к контактам, камере, микрофону и геолокации.

03Реклама и данные SDK

В игре используется Yandex Mobile Ads SDK для межстраничной рекламы и рекламы за вознаграждение. Просмотр за вознаграждение запускается по выбору игрока.

Для загрузки, показа и учёта рекламы сервисы Яндекса обрабатывают IP-адрес, технические сведения об устройстве и рекламных запросах, а также рекламный идентификатор, если он доступен по настройкам Android. Состав данных зависит от версии SDK и устройства.

В конфигурации игры отключены сбор координат средствами SDK, отправка собственных игровых событий в AppMetrica и дополнительная рекламная отчётность AppMetrica. При этом рекламная интеграция запускает AppMetrica в анонимном режиме для служебной работы SDK: отключение игровых событий не означает отсутствия всей технической обработки. Настройки приватности применяются до первого рекламного запроса.

04Хранение и удаление

На устройстве. Сохранения и настройки хранятся до сброса или очистки данных приложения. Сброс прогресса доступен в игре; полностью очистить локальные данные можно в настройках Android → приложения → «Троецарствие: Путь небес» → хранилище → очистить данные. Резервными копиями управляют отдельно в настройках ОС.

При обращении по почте. Адрес отправителя, содержание письма, добровольно указанные имя и технические сведения, вложения используются для ответа и решения вопроса, без рекламных рассылок. Переписка хранится в Яндекс Почте во время рассмотрения и до 12 месяцев после решения вопроса для повторных обращений по той же проблеме, затем удаляется. Запросить более раннее удаление можно по контактному адресу. Не присылайте пароли и другие ненужные для обращения сведения.

У внешних сервисов. Сроки и условия хранения рекламных данных описаны в документах Яндекса выше. Сброс игры не удаляет данные этих сервисов. По вопросам удаления напишите нам; запрос рассматривается в пределах наших обязанностей, при необходимости с привлечением соответствующего сервиса.

05Ваши права

По адресу badalovgames.help@yandex.ru можно запросить сведения об обработке своих данных, их уточнение, ограничение или удаление, а также отозвать согласие, если обработка основана на нём. Запросы рассматриваются в установленном законом порядке. Для защиты прав можно обратиться в Роскомнадзор или суд.

Рекламным идентификатором можно управлять в настройках конфиденциальности Android. Возможности зависят от версии ОС; ограничение идентификатора не отключает рекламу полностью.

Эта Политика информирует об обработке данных и не заменяет отдельное согласие, когда оно требуется.

06Аудитория

Игра рассчитана на подростков и взрослых. Возрастная маркировка указывается в карточке RuStore. Родитель или законный представитель может обратиться к издателю по вопросам обработки данных несовершеннолетнего.

07Сайт политики

Хостинг страницы — GitHub Pages. В её коде нет форм, счётчиков, рекламных скриптов и cookies. GitHub Pages записывает IP посетителей для безопасности; GitHub использует международную инфраструктуру. Условия обработки приведены в политике GitHub и документации Pages.

08Изменения

Политика действует с момента публикации. При изменении функций игры или обработки данных она обновляется. Актуальная редакция и её дата размещаются на этой странице.
